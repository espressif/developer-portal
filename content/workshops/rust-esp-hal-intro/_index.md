Welcome to the **Getting started with esp-hal** workshop!

## About this workshop

In this workshop, you will write bare-metal (`no_std`) Rust firmware for Espressif chips using [esp-hal](https://github.com/esp-rs/esp-hal), the official Rust hardware abstraction layer for Espressif SoCs.

You will start with an empty project generated by `esp-generate` and finish with a board that joins a shared web app over Wi-Fi and talks to the other boards in the room over ESP-NOW. The onboard RGB LED is the common thread: you will first drive it directly through the RMT peripheral, and later let the web app and the other boards set its color.

By the end of the workshop, you will know how to:

- Install the Rust toolchain and the Espressif tools: `espflash` and `esp-generate`
- Generate an esp-hal project from a template and understand what each generated file does
- Configure a peripheral (RMT) and use it to drive a WS2812 addressable LED
- Write async firmware with [Embassy](https://embassy.dev/) and the `esp-rtos` scheduler
- Connect to Wi-Fi with `esp-radio` and exchange data with a web application
- Send and receive ESP-NOW packets between boards without an access point

## Supported boards

Every board-specific command and code snippet in this workshop comes in a tab for each of the boards below. Pick your board in any tab group and all the other tab groups follow.

| Board | Chip | Rust target | RGB LED | BOOT button |
|-------|------|-------------|---------|-------------|
| [ESP32-S31-Function-CoreBoard-1](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s31/esp32-s31-function-coreboard-1/user_guide.html) | ESP32-S31 | `riscv32imafc-unknown-none-elf` | GPIO60 | GPIO61 |
| [ESP32-S31-Korvo-1](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s31/esp32-s31-korvo-1/user_guide.html) | ESP32-S31 | `riscv32imafc-unknown-none-elf` | GPIO37 | GPIO61 |
| [ESP32-C6-DevKitC-1](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c6/esp32-c6-devkitc-1/user_guide.html) | ESP32-C6 | `riscv32imac-unknown-none-elf` | GPIO8 | GPIO9 |
| [ESP32-C5-DevKitC-1](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c5/esp32-c5-devkitc-1/user_guide.html) | ESP32-C5 | `riscv32imac-unknown-none-elf` | GPIO27 | GPIO28 |
| [ESP32-C3-DevKit-RUST-1](https://github.com/esp-rs/esp-rust-board) | ESP32-C3 | `riscv32imc-unknown-none-elf` | GPIO2 | GPIO9 |
| [ESP32-C3-LCDkit](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c3/esp32-c3-lcdkit/user_guide.html) | ESP32-C3 | `riscv32imc-unknown-none-elf` | GPIO8 | GPIO9 (encoder knob) |

All the boards have a WS2812-compatible RGB LED on board, so the code is the same for all of them apart from the pin numbers.

The ESP32-C3-LCDkit has no separate BOOT button: pressing the rotary encoder knob does the same job, because its switch is wired to GPIO9, the BOOT strapping pin.

## Prerequisites

### Required hardware

- Computer running Linux, Windows, or macOS
- One of the boards from the [Supported boards](#supported-boards) table
- USB Type-C data cable (charge-only cables won't work)

### Required software

Install the software **before the workshop** by following [Setup](setup/). The first build downloads and compiles all dependencies, which can take several minutes on a crowded network.

### Required knowledge

- Basic Rust: ownership and borrowing, `struct`s, `enum`s and `match`, `Result` and `Option`. If you are new to Rust, [the Rust book](https://doc.rust-lang.org/book/) chapters 1 to 9 cover all of it.
- No prior embedded or Espressif experience is needed.
